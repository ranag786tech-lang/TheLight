# ✨ The Light - Digital Tasbeeh App

ایک جدید اور خوبصورت ڈیجیٹل تسبیح ایپ جس میں اللہ کے 99 ناموں کی تسبیح، ویژول ایفیکٹس اور بہترین یوزر ایکسپیرینس شامل ہے۔

## 🚀 لائیو لنک
آپ اس ایپ کو یہاں دیکھ سکتے ہیں:
[https://ranag786tech-lang.github.io/the-light/](https://ranag786tech-lang.github.io/the-light/)

## 🌟 نمایاں خصوصیات (Features)
* **99 Names of Allah:** ترجمہ، قرآنی حوالہ اور معاشی اصولوں کے ساتھ۔
* **Dynamic Visuals:** کلک کرنے پر ناموں کا اوپر اڑنا۔
* **Magnetic Glow:** جادوئی روشنی جو انگلی کے ساتھ چلتی ہے۔
* **Haptic Feedback:** ہر 33 کی تسبیح پر وائبریشن۔
